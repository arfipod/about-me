# about-me

Interactive bilingual portfolio for Ángel Rafael Rubio Fernández, built with React, Vite and GitHub Pages.

## Features

- Bilingual UI: Spanish and English.
- Project filtering by area, search query and featured projects.
- Public GitHub repositories only.
- Professional profile and CV section.
- GitHub Pages deployment through GitHub Actions.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## GitHub Pages

This repository is configured to deploy with GitHub Actions. In GitHub, go to:

`Settings -> Pages -> Build and deployment -> Source -> GitHub Actions`

The expected public URL is:

```text
https://arfipod.github.io/about-me/
```
